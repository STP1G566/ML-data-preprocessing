**Группа:** ЕТ-216

## О работе

В рамках лабораторной работы был создан и проанализирован текстовый корпус из 5 документов (21 чанк) и их 8-мерных векторных представлений (эмбеддингов). Проведено сравнение трёх стратегий разбиения текста на чанки и определена стратегия, использованная в исходном датасете. Исследовано поведение метрик `cosine`, `euclidean`, `cityblock` и `dot product` на исходных данных, после L2-нормализации по строкам (`Normalizer`) и после Z-score стандартизации по столбцам (`StandardScaler`). В ходе оценки качества поиска по чанкам были обнаружены и разобраны две логические неточности в формулировке задания, выполнен исправленный расчёт точности, а также построена 2D-визуализация кластеров с помощью PCA.

## Инструкция по запуску

1. Перейдите в папку с лабораторной работой:

   ```
   cd lab7
   
   ```

2. Установите необходимые зависимости:

   ```
   pip install -r requirements.txt
   
   ```

3. Запустите Jupyter Notebook и откройте файл `notebook.ipynb`:

   ```
   jupyter notebook notebook.ipynb
   
   ```

   *(Также ноутбук можно открыть и выполнить сверху вниз в Google Colab — данные автоматически сохраняются в папку `data/` при запуске первой кодовой ячейки.)*
