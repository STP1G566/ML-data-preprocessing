## Содержание
В работе выполнены:
- формирование и сохранение исходных данных в CSV-файл;
- загрузка данных из CSV и первичный анализ структуры;
- выборка и фильтрация строк и столбцов;
- проверка качества данных и расчет статистических метрик;
- выявление выбросов и сравнение среднего с медианой;
- группировка данных по каналам продаж;
- построение гистограммы распределения сумм заказов;
- формирование итогового аналитического вывода для руководителя.
